# Sprint 1 : Core Gameplay Prototype

> 작성일 : 2026.08.02
> 목표 : 플레이어의 핵심 이동 시스템 프로토타입 제작

---

# 목표

플레이어의 핵심 이동 시스템을 구현하여 게임의 기본 재미를 검증한다.

이번 스프린트에서는 아래 세 가지 이동 방식이 자연스럽게 연결되는지 확인한다.

- 기본 이동
- 로프 스윙
- 로켓 반동 이동

---

# 검증 목표

이번 스프린트가 끝났을 때 아래 질문에 답할 수 있어야 한다.

- 기본 이동이 쾌적한가?
- 로프 이동이 빠르고 재미있는가?
- 로켓 반동을 이용한 이동이 자연스러운가?
- 세 가지 이동 방식이 함께 사용해도 재미있는가?

---

# 작업 목록

## Track 0 : Momentum System

### 구현

- 이동 시스템이 생성한 힘을 수집한다.
- 수집한 힘을 하나의 Rigidbody에 적용한다.
- 기본 이동, 로프, 로켓은 Rigidbody를 직접 제어하지 않는다.

### 완료 조건

- Track 0 자체에서는 확인할 수 없음
- Track 1과 병행하며 확인해야 함

## Track 1 : 기본 이동

### 구현

- WASD 이동
- 마우스 시점 회전
- 점프

### 완료 조건

- 기본 FPS 조작이 가능하다.
- Track 0의 물리 적용 매니저가 물리를 적용한다.

---

## Track 2 : 로프 액션

### 구현

- 좌클릭으로 로프 발사
- 앵커에 연결
- 오버워치 레킹볼 스타일 스윙

### 완료 조건

- 빠른 이동이 가능하다.
- 스윙이 자연스럽다.

---

## Track 3 : 로켓 런처

### 구현

- E로 로켓 발사
- 발사 반동 적용

### 완료 조건

- 로켓 발사와 반동이 동시에 발생한다.
- 반동으로 이동할 수 있다.
- 빠른 이동 중에도 조작이 가능하다.
- 카메라 움직임이 과하게 어지럽지 않다.
