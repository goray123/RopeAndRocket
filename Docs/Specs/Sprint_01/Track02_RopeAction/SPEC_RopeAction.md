# 구현 기능

## 로프 발사

- 좌클릭 입력 시 카메라의 방향으로(플레이어의 시점 방향으로) 로프의 앵커가 발사된다.
- 로프 앵커가 Ground Layer와 닿으면 위치가 고정된다.
- 고정된 앵커와 플레이어 사이에 줄이 생성된다.
- 좌클릭 홀드 중 앵커가 유지되며, 홀드 해제 시 앵커가 연결 유무에 관계없이 사라진다.
- 현재는 테스트용으로 좌클릭이 유지되는 한, 앵커는 벽에 닿지 않아도 사라지지 않는다. (최대 사거리 X)

## 로프 액션

- 로프가 연결된 상태에서 WASD 이동 시 앵커를 중심으로 스윙 액션을 한다.
- WASD는 스윙 방향을 보조한다.
- 입력이 없어도 관성으로 스윙이 유지된다.
- 로프가 연결된 상태에서 스페이스 바 입력 시 점프가 나가지 않고, 로프 앵커 쪽으로 플레이어 자신이 끌어당겨진다.
- Space를 누르고 있는 동안 지속적으로 빠른 속도로 당겨진다.

## 스윙 원칙

- 로프는 플레이어의 관성을 유지한다.
- 로프는 플레이어의 속도를 강제로 초기화하지 않는다.

## 카메라

- 스윙 중 카메라는 플레이어를 따라간다.
- 카메라의 추가 흔들림은 적용하지 않는다.

## UI

- 플레이어 시점에 벽이 있을 경우, 로프의 앵커가 닿을 수 있다는 의미로 에임 UI 주변에 부착가능 UI가 나타난다.

## 레퍼런스

- 오버워치 레킹볼

# Input

| 입력 | 동작 |
|------|------|
| 좌클릭 클릭 | 로프 앵커 발사 |
| 좌클릭 홀드 | 앵커 유지 |
| 좌클릭 홀드 해제 | 앵커 삭제 |
| (로프 연결 중) space | 플레이어가 앵커쪽으로 끌어당겨짐 |

---

# Momentum System 연동

Rope Action 관련 컴포넌트는 Rigidbody를 직접 수정하지 않는다.

이동 방향과 이동 힘만 Momentum System으로 전달한다.

---

# Inspector

| 변수 | 설명 |
|------|------|
| Rope Anchor | 로프 앵커 프리팹 |
| Pull Force | 당기는 힘 |
| Swing Force | 스윙 힘 |

- 최대 줄길이는 아직 고려하지 않는다

# 완료 조건

- 로프 액션을 통해 속도감이 증가한다.
- 로프 액션을 통해 다양한 지형을 효율적으로 이동할 수 있다.
- Momentum System을 통해 이동이 적용된다.
